# 虚拟串口桥接

虚拟串口模式将第三方转台控制软件接入设备的 GS-232B WebSocket 服务。

1. 在连接面板选择“网络”，输入设备地址，例如 `192.168.1.50`。
2. 勾选“虚拟串口”。
3. Windows 下选择已创建的虚拟 COM 对：本程序打开“桥接端口”，第三方软件打开“客户端端口”。两个端口必须不同，波特率按第三方软件配置。
4. 点击“连接”。WebSocket 和虚拟串口均就绪后才会显示“已连接”，“当前端口”和控制台会显示第三方软件应打开的端口。
5. 在第三方软件中选择 GS-232B 协议并打开该端口。

Linux/macOS 自动创建 PTY，无需预先配对。第三方软件需支持手动输入端口路径，例如 Linux 下的 `/dev/pts/5`；请使用每次连接后实际显示的路径。

Windows 需要先安装配对虚拟串口驱动并创建 COM 对。本程序使用已有端口对，不安装驱动或创建系统 COM 端口。

桥接使用 `/ws/gs232b` 端点。串口命令按 CR 分行，以原始二进制帧发送；WebSocket 的文本和二进制回复均可接收，完整 CR 行转发至串口。两侧都兼容 CRLF，转发时统一保留 CR。

虚拟串口模式下，界面控制、管理命令和自动轮询停用，由第三方软件控制设备。点击“断开”、WebSocket 断线或虚拟串口停止时会关闭两侧连接，并丢弃尚未完成的行；重连后重新打开显示的端口。
